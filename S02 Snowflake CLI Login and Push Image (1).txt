:: Purpose:
::   Install Snowflake CLI on Windows without manually downloading MSI files.

:: =============================================================================

snow connection list


:: =============================================================================
:: Step: Add Snowflake CLI connection profile for LK77308
:: Purpose:
::   Create a Snowflake CLI connection profile for the LK77308 account.
::
:: ใช้ทำอะไร:
::   ใช้สร้าง profile ชื่อ LK77308 เพื่อให้ Snowflake CLI ใช้เชื่อมต่อ
::   account ที่มี Image Repository สำหรับ Tableau MCP

:: =============================================================================
:: Step: Login Docker to Snowflake Image Registry
:: Purpose:
::   Authenticate Docker with the Snowflake account image registry using the
::   Snowflake CLI connection profile.
::
:: ใช้ทำอะไร:
::   ใช้ login Docker เข้า Snowflake Image Registry
::   เพื่อให้สามารถ push Docker image ไปยัง Snowflake Image Repository ได้
::
:: Connection:
::   LK77308
::
:: Notes:
::   This command must be executed with a role that can view at least one
::   image repository in the Snowflake account registry.
:: =============================================================================

snow spcs image-registry login --connection LK77308

:: =============================================================================
:: Step: Push Tableau MCP Docker image to Snowflake Image Repository
:: Purpose:
::   Upload the tagged Tableau MCP Docker image from local Docker Desktop to
::   Snowflake Image Repository so it can be used by Snowpark Container Services.
::
:: ใช้ทำอะไร:
::   ใช้ส่ง Docker image ของ Tableau MCP เข้า Snowflake Image Repository
::   เพื่อเตรียม deploy เป็น Snowpark Container Services
::
:: Prerequisites:
::   - Docker Desktop is running
::   - snow spcs image-registry login succeeded
::   - Local image has already been tagged with Snowflake registry URL
::
:: Target Image:
::   bflszia-lk77308.registry.snowflakecomputing.com/agent_ai/agent_101/tableau_mcp_repo/tableau-mcp:latest
:: =============================================================================

docker push bflszia-lk77308.registry.snowflakecomputing.com/agent_ai/agent_101/tableau_mcp_repo/tableau-mcp:latest
